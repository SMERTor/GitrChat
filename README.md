# GitrChat — Flutter + Supabase

Приватный общий чат на двоих: вход по имени (анонимная Supabase Auth-сессия), сообщения в реальном времени, presence/typing, смайлики, фото, видеокружочки и переключение темы.

## Что добавлено

- Светлая, тёмная и системная тема; выбор сохраняется на устройстве.
- Выбор фотографии из галереи, уменьшение разрешения до 1600 px и JPEG quality 68 перед загрузкой.
- Запись видеосообщения с фронтальной камеры, максимум 60 секунд; перед отправкой видео перекодируется в профиль Medium (целевой 720p).
- Фото и видео загружаются в приватный Supabase Storage bucket `chat-media`.
- История сообщений сохраняется локально в SharedPreferences. После первой загрузки приложение запрашивает только сообщения новее последней сохранённой записи; уже полученная история не скачивается повторно.
- Фото и видео после просмотра кэшируются локально на телефоне.
- Удаление своего сообщения удаляет запись и соответствующий объект Storage.
- Смайлики доступны кнопкой рядом с полем ввода.

## Supabase

Проект GitrChat уже подключён. В нём применена миграция `add_chat_media_storage`:

- в `public.messages` добавлены `media_path`, `media_type`, `media_duration_seconds`; `body` стал nullable для медиа-сообщений;
- создан приватный bucket `chat-media` с лимитом 50 MiB;
- политики разрешают чтение участникам чата, загрузку и удаление — только в папке собственного UUID.

Не запускайте `schema.sql` поверх уже существующей базы без проверки: он предназначен как ориентир для нового развёртывания. В действующем проекте миграция уже применена.

## Сборка Android

В этой поставке содержится исходный Flutter-код приложения и SQL. Папки `android/` и Gradle wrapper не включены, поэтому сначала в корне проекта выполните:

```bash
flutter create . --platforms android
flutter pub get
flutter run
```

Для APK:

```bash
flutter build apk --release
```

APK появится в `build/app/outputs/flutter-apk/app-release.apk`.

Параметры Supabase уже прописаны как значения по умолчанию в `lib/main.dart`. При необходимости их можно переопределить:

```bash
flutter build apk --release \
  --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
```

## Важные ограничения текущей сборки

- Это исходный проект, а не проверенный APK: в среде подготовки Flutter SDK отсутствует, поэтому `flutter pub get`, `dart analyze` и сборку Android выполнить не удалось.
- Видео-кружок записывается через системный интерфейс камеры, длительность ограничена 60 секундами. Реальный хронометраж в карточке пока не выводится.
- Кэш — локальный кэш приложения, а не экспорт в общую галерею телефона. После очистки кэша медиа можно скачать повторно из приватного Storage.
- Анонимная авторизация удобна для закрытого чата, но имя само по себе не защищает аккаунт: при переустановке приложения пользователь может получить новую сессию. Для реального контроля доступа желательно добавить приглашение/код комнаты.

## Иконка и название

Название приложения: GitrChat. Иконка находится в `assets/gitrchat_icon.png`. После `flutter create . --platforms android` откройте `android/app/src/main/AndroidManifest.xml`, замените значение `android:label` на `GitrChat`, затем выполните `dart run flutter_launcher_icons` для генерации иконок Android.


## Сжатие и анимация отправки

- Фотографии уменьшаются до 1600×1600 и JPEG quality 68 через image_picker.
- Видеокружочки перекодируются `video_compress` в профиль Medium перед загрузкой; исходник не удаляется.
- Во время сжатия/отправки показывается анимированный индикатор и полоска неопределённого прогресса. Это индикатор процесса, не точный процент сетевой передачи.
- При открытии медиа из кэша показывается плавный placeholder.

Перед сборкой выполните `flutter pub get`, чтобы установить `video_compress`.
